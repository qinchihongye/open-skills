## 接口使用说明

### 请求说明

* **请求方式**

  | 请求       | 说明              |
  | ---------- | ----------------- |
  | 路径       | `/【api_path】`   |
  | 请求方式   | 【POST / GET】    |
  | 请求类型   | 【Content-Type】  |
  | 返回值类型 | 【Accept/类型】   |

* **输入结构树**

  ```text
  【请求根对象名或 request】
  ├── 【param_a】
  ├── 【object_b】
  │   └── 【sub_a】
  └── 【items】[]
      └── 【item_a】
  ```

* **【请求根对象名或 request】字段说明**

  | 字段名       | 数据类型     | 是否必须 | 说明         |
  | ------------ | ------------ | -------- | ------------ |
  | 【param_a】  | 【类型】     | 【是/否】 | 【字段说明】 |
  | 【object_b】 | object       | 【是/否】 | 【字段说明】 |
  | 【items】    | list[object] | 【是/否】 | 【字段说明】 |

  **【请求根对象名或 request】.【object_b】字段说明**

  | 字段名    | 数据类型 | 是否必须 | 说明         |
  | --------- | -------- | -------- | ------------ |
  | 【sub_a】 | 【类型】 | 【是/否】 | 【字段说明】 |

  **【请求根对象名或 request】.【items】[] 字段说明**

  | 字段名     | 数据类型 | 是否必须 | 说明         |
  | ---------- | -------- | -------- | ------------ |
  | 【item_a】 | 【类型】 | 【是/否】 | 【字段说明】 |

* **鉴权 / Token 计算规则**

  | 项目          | 说明                                                |
  | ------------- | --------------------------------------------------- |
  | 鉴权方式      | 【无 / Bearer Token / API Key / 自定义签名】        |
  | 凭据传递位置  | 【请求头 / Query 参数 / Cookie / 请求体】           |
  | 凭据格式      | 【`Bearer <token>` / 自定义格式 / 不适用】          |
  | 获取方式      | 【凭据获取方式或配置位置，不填写明文】              |
  | 有效期与刷新  | 【有效期、刷新方式或“不适用”】                      |

  **无鉴权示例**

  无。

  **Bearer Token 示例**

  ```http
  Authorization: Bearer 【token】
  ```

  **API Key 示例**

  ```http
  X-API-Key: 【api_key】
  ```

  **自定义签名示例**

  ```text
  待签名串 = 【timestamp】 + "\n" + 【nonce】 + "\n" + 【request_body】
  signature = HMAC-SHA256(【secret】, 待签名串)
  ```

  ```http
  X-Timestamp: 【timestamp】
  X-Nonce: 【nonce】
  X-Signature: 【signature】
  ```

* **请求示例**

  ```json
  {
      "【param_a】": "【示例值】",
      "【object_b】": {
          "【sub_a】": "【示例值】"
      },
      "【items】": [
          {
              "【item_a】": "【示例值】"
          }
      ]
  }
  ```

### 响应说明

* **输出结构树**

  ```text

  ├── 【field_a】

  │   └── 【sub_a】
  └── 【items】[]
      └── 【item_a】
  ```

* **【响应根对象名或 response】字段说明**

  | 字段名       | 数据类型     | 是否必须 | 说明         |
  | ------------ | ------------ | -------- | ------------ |
  | 【field_a】  | 【类型】     | 【是/否】 | 【字段说明】 |
  | 【object_b】 | object       | 【是/否】 | 【字段说明】 |
  | 【items】    | list[object] | 【是/否】 | 【字段说明】 |

  **【响应根对象名或 response】.【object_b】字段说明**

  | 字段名    | 数据类型 | 是否必须 | 说明         |
  | --------- | -------- | -------- | ------------ |
  | 【sub_a】 | 【类型】 | 【是/否】 | 【字段说明】 |

  **【响应根对象名或 response】.【items】[] 字段说明**

  | 字段名     | 数据类型 | 是否必须 | 说明         |
  | ---------- | -------- | -------- | ------------ |
  | 【item_a】 | 【类型】 | 【是/否】 | 【字段说明】 |

* **响应示例**

  **响应成功**：

  ```json
  {
      "【field_a】": "【示例值】",
      "【object_b】": {
          "【sub_a】": "【示例值】"
      },
      "【items】": [
          {
              "【item_a】": "【示例值】"
          }
      ]
  }
  ```

  **响应失败**：

  ```json
  {
      "【error_field】": "【失败原因】"
  }
  ```
