# references 怎么用

* 本目录是**可选查阅**，不是硬依赖
* **硬规则只在** `../SKILL.md`
* 设计原则
  1. **通用**：不绑定具体业务仓库
  2. **短**：只放可复制片段
  3. **可替换**：改示例不必改 `SKILL.md` 门禁与模式

## 文件索引

* 何时打开哪个文件

  | 文件 | 何时打开 |
  |------|----------|
  | `do-dont.md` | 拿不准标题后能否直接写、模式 A 能改到哪 |
  | `skeletons.md` | 模式 B 新建，需要通用骨架起笔 |
  | `elements.md` | 需要代码/表/公式/链接/图的标准挂载写法 |
