# 正反例（通用）

* 配合 `SKILL.md` §2，只看**形状**，主题可替换

## 标题后必须先 `*`

* 错误

  ```markdown
  ## 背景

  这里直接写正文。
  ```

* 正确

  ```markdown
  ## 背景

  * 这里写正文；代码、表、编号都挂在这条或同级其它 `*` 下。
  ```

## 禁止标题后直接编号 / 代码

* 错误

  ````markdown
  ## 设计要点

  1. 第一点
  2. 第二点

  ## 流程

  ```mermaid
  flowchart TD
    A --> B
  ```
  ````

* 正确

  ````markdown
  ## 设计要点

  * 要点
    1. 第一点
    2. 第二点

  ## 流程

  * 主流程

    ```mermaid
    flowchart TD
      A --> B
    ```
  ````

## 禁止 `####`；用 `*` 当分类

* 错误

  ```markdown
  ## 数据

  ### 表 A
  #### 字段
  #### 备注
  ```

* 正确

  ```markdown
  ## 数据

  * 表 A 字段

    | 字段 | 说明 |
    | ---- | ---- |
    | id | 主键 |

  * 表 A 备注

    补充说明……
  ```

## `*` 少而完整

* 错误（一句一条）

  ```markdown
  ## 说明

  * 先做 A
  * 再做 B
  * 然后 C
  * 最后 D
  ```

* 更好（一条分类 + 编号）

  ```markdown
  ## 说明

  * 操作顺序
    1. 先做 A
    2. 再做 B
    3. 然后 C
    4. 最后 D
  ```

## 模式 A：只改格式

* 原文

  ```markdown
  ## 偏差

  活动人数取整需要关注。
  ```

* 允许（格式）

  ```markdown
  ## 偏差

  * 活动人数取整需要关注。
  ```

* 禁止（改内容）

  ```markdown
  ## 偏差

  * 活动人数的取整问题值得后续重点优化，建议……
  ```
