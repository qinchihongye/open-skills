# 正反例（通用）

* 配合 `SKILL.md` §2，只看**形状**，主题可替换

## 标题后必须先 `*`

* 错误

  ```markdown
  ## 背景

  这里直接写正文。
  ```

* 正确

  ```markdown
  ## 背景

  * 这里写正文；代码、表、编号都挂在这条或同级其它 `*` 下。
  ```

## 禁止标题后直接编号 / 代码

* 错误

  ````markdown
  ## 设计要点

  1. 第一点
  2. 第二点

  ## 流程

  ```mermaid
  flowchart TD
    A --> B
  ```
  ````

* 正确

  ````markdown
  ## 设计要点

  * 要点
    1. 第一点
    2. 第二点

  ## 流程

  * 主流程

    ```mermaid
    flowchart TD
      A --> B
    ```
  ````

## 标题默认不写章节序号（防双重编号）

* 错误（标题自带序号；编辑器/PDF 再自动编号会叠成 `1.1 1. 版本记录`）

  ```markdown
  # 1 【接口名称】-接口文档

  ## 1. 版本记录

  ### 1.1 基础信息

  ## 2. 摘要
  ```

* 正确（默认只写语义名）

  ```markdown
  # 【接口名称】-接口文档

  ## 版本记录

  ### 基础信息

  ## 摘要
  ```

* 例外：仅当用户明确要求「标题带序号」时，才写 `## 1. 版本记录` 这类形式。

## 禁止 `####`；用 `*` 当分类

* 错误

  ```markdown
  ## 数据

  ### 表 A
  #### 字段
  #### 备注
  ```

* 正确

  ```markdown
  ## 数据

  * 表 A 字段

    | 字段 | 说明 |
    | ---- | ---- |
    | id | 主键 |

  * 表 A 备注

    补充说明……
  ```

## `*` 少而完整

* 错误（一句一条）

  ```markdown
  ## 说明

  * 先做 A
  * 再做 B
  * 然后 C
  * 最后 D
  ```

* 更好（一条分类 + 编号）

  ```markdown
  ## 说明

  * 操作顺序
    1. 先做 A
    2. 再做 B
    3. 然后 C
    4. 最后 D
  ```

## 禁止 `*` 嵌套 `*`；平级拆顶格，从属挂同一条

* 错误（`*` 下再套 `*`）

  ```markdown
  * data 字段说明

    两种写法二选一。

    * 写法 A：结构化字段

      | 参数名 | 说明 |
      | ------ | ---- |
      | out_a | …… |

    * 写法 B：文本业务体

      返回在 robot_text 中。
  ```

* 正确（从属：同一 `*` + 段落 / 表；或编号）

  ```markdown
  * 响应参数

    | 参数名 | 是否必须 | 类型 | 说明 |
    | ------ | -------- | ---- | ---- |
    | code | 是 | int | 状态码 |
    | data | 是 | json | 响应数据 |

    data 字段说明：两种写法二选一，不要同时保留。

    写法 A：data 内为结构化字段（推荐先写字段表）

    | 参数名 | 是否必须 | 类型 | 说明 |
    | ------ | -------- | ---- | ---- |
    | out_a | 是 | string | …… |

    写法 B：data 内业务体为文本（如 markdown / 纯文本）

    data 为 json 字段，业务返回在 robot_text 中，类型为 string。
  ```

  或：

  ```markdown
  * 响应参数

    顶层字段表……

    data 字段说明：两种写法二选一。
    1. **写法 A**：结构化字段（先写字段表）

       | 参数名 | 说明 |
       | ------ | ---- |
       | out_a | …… |

    2. **写法 B**：文本业务体

       返回在 robot_text 中。
  ```

* 正确（平级：多个顶格 `*`）

  ```markdown
  * 写法 A：data 内为结构化字段

    | 参数名 | 说明 |
    | ------ | ---- |
    | out_a | …… |

  * 写法 B：data 内业务体为文本

    返回在 robot_text 中。
  ```

## 模式 A：只改格式

* 原文

  ```markdown
  ## 偏差

  活动人数取整需要关注。
  ```

* 允许（格式）

  ```markdown
  ## 偏差

  * 活动人数取整需要关注。
  ```

* 禁止（改内容）

  ```markdown
  ## 偏差

  * 活动人数的取整问题值得后续重点优化，建议……
  ```
