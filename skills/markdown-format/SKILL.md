# markdown-format

通用的个人笔记向 Markdown 指令。非「标准 GitHub 文档风」；非 agent 的 `SKILL.md` 写法。  
**硬规则以本文件为准。** 需要抄形状时可选查阅 `references/`（见该目录 README）。

## 0. 门禁（先执行）

1. **create-skill** / 创建 skill / 写 skill 包文档 → **停止，不用本 skill**  
2. 路径在 **skill 目录**内（`~/.grok/skills/**`、`.grok/skills/**`、`~/.claude/skills/**`、用户 skill 包如 `myskills/<skill名>/**`、`**/skills/**` 包）→ **默认停止**  
3. **唯一例外**：用户强制本 skill（`markdown-format` / `/markdown-format` 等）**且**点名**一个具体 .md 路径** → 只处理该文件  
4. 无效强制：只说整理整个 skills 目录；create-skill 自动生成 `SKILL.md`  
5. 其它笔记/业务 `.md` → **必须**用本 skill  

同对话：skill 工作不用本 skill；笔记 md 用本 skill。

## 1. 模式分流

| 模式 | 时机 | 规则 |
|------|------|------|
| **A 修改** | 已有笔记：整理/规范/格式化/检查 | **只改格式，绝不改内容** |
| **B 新建** | 新建笔记、生成 md、整理成新笔记 | **全文按规则写**（含标题/`*` 克制） |

默认：

- 已有文件 + 整理/改一下 → **A**  
- 仅改格式 → **A**  
- 新建/写一篇/生成 md/整理成笔记（无已有路径）→ **B**  
- 已有文件但要扩写业务内容 → 内容听用户；**格式仍须合规**

### 模式 A（铁律）

**允许：** 标题下补顶格 `*`；无序 `-`→`*`；缩进；围栏语言标签；代码/表/公式/图挂回所属 `*`；修围栏与 `---`。

**禁止：** 润色改写；增删事实；改数值/公式/代码含义；改标题用词；为少标题并节/删节；擅自删口语或最终代码。

最小手术且**尽量保留原句**：裸段前加 `* `。改完只列格式改动点。

### 模式 B

按 §2–§3 生成完整笔记；少标题、厚内容。

## 2. 硬性格式规则

### 2.1 标题后起笔

有正文的标题下，**第一条必须是顶格 `*`**。

标题下禁止直接：裸段、裸编号、裸围栏（含 mermaid）、裸 `$$`、裸表、裸图、裸 `>`。

仅允许例外：

1. 紧接下一级标题（中间无正文）  
2. 仅 `---`  
3. 文首第一个 `#` **之前**的 `[toc]`  

编号/代码/公式/表/图/引用 → 挂在某个 `*` 下。

### 2.2 标题（B 硬性；A 不重组目录）

- 最多三级：`#` / `##` / `###`，**禁止 `####`+**  
- **尽量少标题**；更深分类用 `*`  
- 一文多个 `#` 可以，但数量克制  
- 可选 `[toc]` 仅在第一个 `#` 前  
- 中文标题 + 英文专有名词  

模式 A：**不为克制标题而并节/删标题**（除非用户明确要求精简层级且保留全部原文）。

### 2.3 列表

- 无序只用 `*`（任务列表除外可用 `- [ ]`）  
- `*` = 分类桶：**少而完整**；细节用 `1. 2. 3.` 或段落挂在同一 `*` 下  
- 禁止一句一条刷 `*`；嵌套建议 ≤3 层  
- 导语按需：`* 代码` / `* 相关解释` / `* 主流程` 等，不必每段都套  

### 2.4 代码 / mermaid

- 先 `*` 导语再围栏；围栏相对 `*` 缩进  
- 必须语言标签；未知用 `text`  
- 节后可用 `---`  

### 2.5 链接 / 图 / 公式 / 表

- 重要资料双写：`[text](url)` + 缩进 `>url`  
- 图挂步骤 `*` 下  
- 行内 `$...$`，行外 `$$...$$` 挂 `*` 下；话→式→其中  
- 表挂 `*` 下；表头+分隔行齐全  

### 2.6 可选（默认不用）

任务列表、脚注、HTML：仅渲染器需要时。强调优先 `**加粗**` 与行内代码。

### 2.7 语气（模式 B）

中文为主；标识符行内代码；笔记体口语可接受。

## 3. 骨架选型（模式 B，按需选用）

少标题即可，不必套满每一节。完整可复制骨架见 `references/skeletons.md`。

- **算法/原理：** 主题 → 介绍 → 公式 → 代码 → 解释 → 示例  
- **教程/实操：** 摘要 → 环境 → 实现 → 使用 → 可选最终代码  
- **业务/混合：** 少量 `##` + `*` 分类（数据、口径、输出、流程等）  
- **其它笔记：** 同样遵守 §2；按内容自拟少量标题，用 `*` 分类承载细节  

正反例：`references/do-dont.md`。元素挂载：`references/elements.md`。  

## 4. 工作流

1. 门禁 §0  
2. 模式 A/B §1  
3. B：少标题大纲 → 顶格 `*` 填内容；A：只做格式手术  
4. 自检：  
   - [ ] 门禁通过（非 skill 夹，或已强制单文件）  
   - [ ] 模式正确  
   - [ ] 有正文的标题下第一条为顶格 `*`  
   - [ ] 无裸段/编号/围栏/表/`$$`/`>`  
   - [ ] B：无 `####`+；标题少；`*` 少而完整  
   - [ ] 围栏有语言标签；表在 `*` 下  
5. 勿把本 skill 原文抄进用户笔记  

## 5. 输出

- **A：** 只交格式修复 + 简短格式说明  
- **B：** 完整合规笔记  
- 用户明确例外时从其例外（A 默认仍只格式，除非允许改内容）
